  TOOL LIMITATIONS
------------------------------------------------------------------------
  1. Does NOT follow multi-hop redirect chains — only the first
  redirect is inspected.
  2. JavaScript-based redirects in Single-Page Applications (SPAs) may
  be missed; the tool reads the initial HTML but does not execute
  JavaScript.
  3. POST-based redirects are not tested — only GET parameters.
  4. Authenticated endpoints (login-required) are skipped unless a
  session cookie is provided.
  5. WAF or rate-limiting on the target may produce false negatives by
  blocking test requests.
  6. Encoded or obfuscated payloads beyond the built-in set may bypass
  detection.
  7. This tool confirms redirect behavior against a canary domain; it
  does NOT verify the full exploitability of each finding (e.g., whether
  a victim user would click the crafted link).
  8. Results should always be manually verified before inclusion in a
  security report.
